# Armors
Here are the special armors for Rila Ultima Online.

NOTE
{: .label .label-red }


```
Armor system is very different from original Ultima Online.
 - You don't have to collect every parts of the armor.
 - Double clicking makes you wear all parts.
 - You should double click again for unequiping it.
 - Some armors may need to be combined with 3 parts for getting ready. (IT WILL BE EXPLAINED HERE!)

```
