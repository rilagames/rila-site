# Loot and Equipment

Hunt creatures for progression and check each item's requirements before equipping it. The equipment catalogs document the implemented stats and effects.

## Creature rewards

Creature XP is awarded through the contribution and party rules. You must meet a creature's level requirement to attack it or receive its XP.

An item's presence in the catalog does not guarantee that it drops from a named creature. Acquisition details are shown only where confirmed; unlisted prices and drop locations are not implied.

## Durability

Rila special equipment has unlimited durability. See [Equipment Durability]({{ '/damageableitems-system/' | relative_url }}) for the exact categories.

## Death and recovery

Use the current in-game corpse and region rules when recovering items. No universal no-loot protection, automatic safe-zone return or fixed ten-death item lifetime is advertised by this guide.
