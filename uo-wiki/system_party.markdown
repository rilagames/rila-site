# Grup Sistemi

Diğer oyuncularla birlikte hareket etmek için Ultima Online’ın grup sistemini kullanabilirsin.

- `/add`: oyuncu davet et.
- `/accept`: daveti kabul et.
- `/quit`: gruptan ayrıl.

Karakter penceresindeki **Grup** düğmesi de grup arayüzüne erişim sağlar.
