## Effect

Successful weapon or unarmed hits that deal actual damage have a **25% chance** to add **10 base physical damage** to the main target. Normal physical armor reduction applies and can reduce the bonus to zero. Spell and poison damage do not trigger the effect.

## Wearing and availability

Double-click this item in your own backpack to equip it. It uses the **cloak slot**; another special item using the same slot is an alternative, not an additional stacking slot. Gloves and masks use accessory layers so they can be worn with the one-piece Armor Suit. The server checks the level and STR requirements.

No creature drop or crafting recipe is currently configured for this item. Staff can access the current catalog with `.RilaSpecialItems` or `.RilaOzelEsyalar`.
