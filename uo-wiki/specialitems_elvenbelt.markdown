# Elven Belt

| Property | Current value |
|---|---|
| Required level | 42 |
| Required STR | 0 |
| STR bonus | +20 |
| DEX bonus | +0 |
| Armor bonus | +10 |
| Durability | Infinite — does not wear out or break from use |
| Versions | One version; no Mark tiers |

## Effect

Adds **+20 STR and +10 armor** while worn. The bonuses are removed when the item is unequipped.

## Wearing and availability

Double-click this item in your own backpack to equip it. It uses the **belt slot**; another special item using the same slot is an alternative, not an additional stacking slot. Gloves and masks use accessory layers so they can be worn with the one-piece Armor Suit. The server checks the level and STR requirements.

No creature drop or crafting recipe is currently configured for this item. Staff can access the current catalog with `.RilaSpecialItems` or `.RilaOzelEsyalar`.
