# Stat System
**.stat**
```
You can use .stat command for check your base stats. It has always been locked. You don't need to do anything.
Max stats are these without any wear;
Str = 400
Dex = 200
Int = 200

```

**Stat Regen**
```
Without any additional wear;
+3 hp per 2 seconds
+1 mana per seconds
+1 stam per seconds

```
