# Ethereal Newfoundland

![Ethereal Newfoundland in the live Rila client]({{ '/assets/img/mount_newfoundland_live.webp' | relative_url }})

*In-game screenshot captured on 25 October 2026.*

Newfoundland is one of Rila's **20 ethereal mount types**. It is carried as an item and ridden directly; you do not tame a separate animal to use this version.

| Property | Current value |
|---|---|
| Type | Ethereal mount item |
| Follower slots while mounted | 1 |
| STR / DEX / INT bonus | None |
| Mount-specific level requirement | None |
| Appearance | Normal Newfoundland artwork and color |

## Using the mount

1. Keep the Ethereal Newfoundland item in your own backpack.
2. Double-click the item while alive and unmounted.
3. Dismount through the normal character controls. The **same item** returns to your backpack.

You must have one free follower slot. Region restrictions, mount blocks, trading and character-form restrictions still apply. You cannot activate it while paralyzed, frozen or casting a spell. Another player's backpack cannot be used as the source.

On death, the mount returns to item form. Mount state is saved with the world and survives a server restart. This is an ethereal item lifecycle; it is not a guarantee of immunity to every dismount mechanic.

## Bonuses and acquisition

This mount does not grant a stat bonus. The old wiki's 10/10 mount durability system does not apply to the current ethereal items. Acquisition locations and prices have not been published here.
